PREFIX acad: <../ontologia.ttl#>
PREFIX schema: <https://schema.org/>

SELECT ?docente ?departamento ?unidade WHERE {
  ?p a acad:Docente ;
     schema:name ?docente ;

PREFIX skos: <http://www.w3.org/2004/02/skos/core#>

Quais são as publicações de uma docente e quem são seus coautores?

Filtra as instâncias de Artigo pela propriedade autor ligada a Ana. OPTIONAL mantém artigos individuais e o filtro exclui Ana da coluna de coautoria.

Arquivo SPARQL · Resultado CSV

Ver consulta
PREFIX acad: <../ontologia.ttl#>
PREFIX schema: <https://schema.org/>

SELECT ?publicacao ?ano ?coautor WHERE {
  VALUES ?d { <../perfis/ana-martins.html> }
  ?d a acad:Docente .
  ?p a acad:Artigo ;
     schema:name ?publicacao ;
     acad:ano ?ano ;
     acad:autor ?d .
  OPTIONAL {
    ?p acad:autor ?outro .
    FILTER(?outro != ?d)
    ?outro schema:name ?coautor .
  }
}
ORDER BY ?ano ?publicacao ?coautor

Quais pessoas estão vinculadas a uma unidade acadêmica específica?

O caminho (departamento|curso)/unidade chega ao Instituto de Ciências Exatas a partir das duas categorias de perfil.

Arquivo SPARQL · Resultado CSV

Ver consulta
PREFIX acad: <../ontologia.ttl#>
PREFIX schema: <https://schema.org/>

SELECT ?pessoa ?unidade WHERE {
  VALUES ?u { <../recursos.html#unidade-exatas> }
  ?p schema:name ?pessoa ;
     (acad:departamento|acad:curso)/acad:unidade ?u .
  ?u a acad:Unidade ;
     schema:name ?unidade .
}
ORDER BY ?pessoa
